## 📌 주요 서비스

1. **불법건축물 양성화 특별법**
   - 2026.12.17 시행 특정건축물 정리에 관한 특별조치법 대응
   - 30초 자가진단 및 예상 이행강제금/과태료 모의 계산기 탑재
2. **건축행정 (용도변경·건축허가·신고)**
   - 상가 임차 전 용도변경 사전 검토
   - 신축·증축·대수선 허가/신고, 가설건축물 축조신고, 건축물대장 정리, 해체계획서
3. **아파트 행위허가**
   - **우리 집 공사 (전유부)**: 발코니 확장, 비내력벽 철거, 상가 용도변경, 세대구분형 공동주택
   - **관리사무소·입주자대표회의 (공용부)**: 주민공동시설 용도전환, 공용부 대수선, 전기차 충전시설, 부대·복리시설 신축/리모델링, 조경·주차장 등
4. **무료 온라인 상담 신청**
   - 로컬 자동 임시저장(Draft) 및 실시간 유효성 검사, 서류 첨부 지원
